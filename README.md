# COVID-19-Data-Science-Project
COVID-19 EDA, Data Wrangling, Visualization and Machine Learning
## Dataset

The COVID-19 dataset used in this project is provided by Our World in Data.

**Download Dataset:**  
https://catalog.ourworldindata.org/garden/covid/latest/compact/compact.csv

The dataset contains global COVID-19 cases, deaths, vaccinations and other related statistics.
